# Church of Christ Lugbe

A modern, professional platform for the Church of Christ, Lugbe, Abuja.

## Features
- Premium, responsive design with a custom 3D Hero Carousel.
- Modern typography and color palette.
- Worship schedule and service times integration.
- Fast, optimized React frontend with Vite.
- Golang backend for dynamic content management.

## Project Structure
- `/frontend`: React + Vite + Tailwind CSS.
- `/backend`: Golang + Firebase Firestore.

## Getting Started

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`

### Backend
1. `cd backend`
2. `go run main.go`
